# yarngo studio

yarngo studio is a macOS app that speaks text in your own voice, running entirely on your own machine.

## Highlights

- Clone a voice from one 20-second reading of a script the app gives you.
- Five models, downloaded on demand: dots.tts MF at two precisions, dots.tts SOAR, Step-Audio-EditX, LongCat-AudioDiT 3.5B.
- No account, no upload, and no network while generating.
- Speech runtimes are signed with The Update Framework and update in place, keeping the previous one.
- Apple silicon, macOS 13 or later.

## Install

Download the `.dmg` from [Releases](https://github.com/getlatentic/yarngo-artifacts/releases/latest), open it, and drag **yarngo studio** into Applications. It is notarized, so it opens without warnings. The first run downloads a speech runtime (~350 MB) and the model you pick.

## Status

Alpha. The enrolment script is English only.
